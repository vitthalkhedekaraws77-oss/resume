# Vitthal Khedekar — Portfolio

A responsive React, TypeScript, and Vite portfolio built from the profile details supplied in chat.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with `npm run build`, or preview the build with `npm run preview`.

## Resume and profile completeness

The workspace did not contain `resume.pdf`. A resume download is therefore not included; add the real PDF at `public/resume.pdf` before linking a download button. No project, education, employment, certification, achievement, email, or professional-profile details were supplied, so those sections and links are intentionally omitted.
